# India Macro Reflexivity Dashboard — Phase 1

Local research dashboard with a FastAPI API, Next.js UI, PostgreSQL persistence, vintage-aware observations, deterministic scoring, and one FX alert rule. **Every included reading is synthetic DEMO data generated by a simple formula. No value is a market quote.** The default dashboard date is 31 October 2026 at 00:00 IST; it does not imply current market conditions.

## Start

```sh
docker compose up --build
```

Open [dashboard](http://localhost:3000), [API docs](http://localhost:8000/docs), and [health](http://localhost:8000/api/v1/health). The API container runs `alembic upgrade head` and the idempotent seed before serving. To run migrations manually:

```sh
docker compose run --rm api alembic upgrade head
```

## Host on smarthedge.in

Point the domain's A/AAAA records to the server and allow inbound TCP 80/443 and UDP 443. Then start the optional Caddy service:

```sh
API_DOCS_URL=https://smarthedge.in/docs docker compose --profile production up -d --build
```

The [Caddyfile](Caddyfile) enables HTTPS automatically and routes the web app, API, and OpenAPI docs through the same domain. This remains a **public DEMO site** until real feeds and production authentication are configured. Caddy's certificate state is stored in the `caddy_data` volume. The local stack still starts without Caddy via `docker compose up --build`.

## Data and configuration

- `config/indicators.yaml` defines the 12 Phase 1 metrics, units, source priority, frequency and freshness expectations.
- `config/rules.v1.yaml` defines provisional thresholds, signal weights, cycle weights and the FX alert.
- `packages/jobs/seed.py` creates deterministic synthetic observations in PostgreSQL. Re-running it does not duplicate rows.
- `DEMO_MODE=true` excludes all non-demo observations. `DEMO_MODE=false` excludes all demo observations and will show missing data until a verified connector/import is configured.
- `DATABASE_URL` and `ADMIN_TOKEN` are environment variables. The latter is reserved for future write endpoints; Phase 1 exposes no admin write route.

The API uses `published_at` and `ingested_at` for `system_known` as-of queries. `source_known` series queries use publication time only. Observation rows remain immutable by vintage. All timestamps are stored in UTC and displayed as IST in the UI.

## Phase 1 API

Implemented: `/api/v1/health`, `/api/v1/sources/health`, `/api/v1/indicators`, `/api/v1/indicators/{id}/series`, `/api/v1/dashboard`, `/api/v1/cycles/{id}`, `/api/v1/alerts`, `/api/v1/alerts/{id}`, `/api/v1/config/rulesets`. OpenAPI is at `/docs`. Other contracts in the specification are planned for later phases; see [implementation decisions](docs/implementation-decisions.md).

This application is market research software, not investment advice. Version `v1` thresholds are hypotheses and have not been historically calibrated.
