## Approval evidence package for any provider

Record the legal entity granting permission, signed agreement or exact open-licence text and version, covered indicators, historical dates, use cases, storage duration, backfill, public display and attribution obligations. Attach original publisher bytes, source URL, exact observation period, independently documented publication timestamp, revision/vintage marker and source-definition version. The importer and independent reviewer must inspect both rights and evidence; SHA-256 proves retained byte identity only. The existing archive size limit is 750 KB, so a larger original file requires a reviewed implementation change rather than truncation. Do not contact a provider or use a datafeed credential without operator authorisation.

**Current outcome:** no Indian provider has supplied this complete package. No Indian observation is eligible for source-backed staging import or public display. The prior official U.S. Treasury 10-year staging observation remains the only connected source-backed indicator.
