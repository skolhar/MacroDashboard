## Acquisition gates

For each candidate, record a source-specific contract or explicit open licence that covers **download, storage of original bytes, processing, historical backfill and public display**. A URL, website accessibility, attribution or SHA-256 match is not that approval. Retain original publisher bytes and an independent publication notice or other defensible timestamp evidence; identify revisions and definition changes before creating the extract. Submit through the existing source archive and require a different scoped reviewer to approve the release. The `source_known` replay uses publisher time; `system_known` uses actual SmartHedge ingestion time. Never backdate ingestion.

## Current activation result

No candidate met all gates. No Indian feed was fetched for ingestion, no public-facing Indian observation was added, and the External Liquidity Monitor remains `DATA_UNAVAILABLE` / N/A for the relevant Indian risk inputs. The existing official U.S. Treasury 10-year observation in isolated staging is the only previously connected source-backed indicator. The immediate external requirements are written FBIL, AMFI, RBI and NSDL usage decisions; original historical release files and publication evidence; a daily 10-year definition; NSDL flow-specific reporting and licence terms; and independent RBI forward sign review. Provider correspondence requires operator authorisation and is not part of this audit.
