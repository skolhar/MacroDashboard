# Phase 1 implementation decisions

1. **Synthetic fixture only.** `seed.py` creates formula-based numbers under provider `synthetic_fixture` and quality `demo`. They are arbitrary test inputs, not fabricated claims about Indian or global markets. The page and API label DEMO. No licensed feed or credential is assumed.
2. **Incomplete overall score.** No IT/AI priority metric is in the Phase 1 list. The IT cycle is unavailable and the headline score stays N/A. This avoids silently redistributing its 10% weight. Coverage still reports the exact configured weight represented by valid signals.
3. **FX alert scope.** The first four FX conditions are computed from features. Forward liabilities are shown as context but are not numerically triggered until sign conventions and comparable releases are validated. The alert remains UNKNOWN if too few conditions can be evaluated. Phase 2 will add persisted alert lifecycle, recovery hysteresis and complete cross-loop rules.
4. **Freshness.** Daily synthetic records use a weekday check; this prevents weekend false staleness. Exchange holidays require a licensed/maintained market calendar and remain a Phase 2 item. Monthly and weekly series use configured age windows and publication lags, and are never presented as daily updates.
5. **API scope.** The read-only Phase 1 endpoints are implemented. Graph, scenario, replay presentation, events, and authenticated admin import/ingestion routes belong to later phases. The underlying observation query already enforces as-of publication and ingestion time for deterministic computation.
6. **No PE premium.** Phase 1 reports separate P/E series and percentile signals. It does not divide trailing and forward multiples without a comparable basis.
7. **No score persistence yet.** The schema includes score snapshot and alert event tables for auditability. Phase 1 computes dashboard scores on request; persisted recomputation and history are scheduled for Phase 2.
8. **Source governance.** Candidate publisher names in the registry are not active connectors. No vendor data is copied, scraped or redistributed. The connector package is a boundary for future approved adapters.
